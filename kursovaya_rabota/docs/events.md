# События GA4

Сверь список с `js/analytics.js`: в таблицу попадают только те события, которые реально отправляются из кода и проверены в DebugView.

| Событие | Когда срабатывает | Свой параметр | Ключевое |
|---|---|---|---|
| `page_view` | Открытие страницы (автоматически) | — | нет |
| `generate_lead` | Успешная отправка формы заявки | `request_id`, `language` | да |
| `form_start` | Первое заполнение поля формы | — | нет |
| `level_test_start` | Начало теста уровня | — | нет |
| `level_test_complete` | Тест уровня завершён | `score` | нет |
| `click_phone` | Клик по телефону | — | нет |
| `click_social` | Клик по ссылке на соцсеть | `network` | нет |

Параметры `request_id`, `language`, `score`, `network` нужно зарегистрировать в GA4 как пользовательские определения (Admin → Custom definitions).
